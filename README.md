# Mejorador de audio

App web que mejora grabaciones de voz (ruido, timbre, volumen).
Todo el procesamiento ocurre en el navegador: el audio nunca sale del dispositivo.

- `web/`   → la app (HTML, JS, CSS), publicada en GitHub Pages
- `train/` → scripts Python de entrenamiento (no forman parte de la app)
- `tests/` → pruebas
- `docs/`  → notas

Demo: https://franciscode0o0.github.io/mejorador-audio/
