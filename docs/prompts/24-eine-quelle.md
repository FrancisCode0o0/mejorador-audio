# 24 · Arbeitsweise – eine einzige Quelle für den Plan

- **Datum:** 22.10.2026
- **Werkzeug:** Claude (Chat auf claude.ai), kein Code
- **Gruppe:** ergänzend (Arbeitsweise)

## Prompts (Original auf Spanisch, sinngemäß übersetzt)

Anlass: Claude hatte gesagt, alles sei aktuell, ohne eine zweite Notiz
und die anderen Chats gelesen zu haben; eine Entscheidung fehlte. Fran
verlangte eine strukturelle Lösung statt eines Flickens und fragte dann:

> Und wenn das Repository angelegt wird, gibt es dann auch die Gefahr,
> dass etwas auseinanderläuft? Das muss jetzt gelöst werden.

## Antwort (Zusammenfassung)

- Ursache: zwei Orte (Plan und Notiz vom Handy) und eine nur lesbare
  Kopie, die bis zum Synchronisieren ein Standbild ist.
- Regel: Der Plan existiert immer an genau **einem** Ort, den alle Chats
  (Handy und PC) schreiben können; keine Notizen daneben.
- Er zieht ins private Repository nur um, wenn ein Chat vom Handy dort
  wirklich pushen kann („Option A", später bestanden).

## Entscheidung (Fran)

Projektanweisungen v4: Jeder Chat liest zuerst den Plan und die letzten
Chats; nie „aktuell" sagen, ohne es geprüft zu haben; kein Chat endet,
ohne seine Entscheidungen in den Plan zu schreiben.
